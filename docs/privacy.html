Oh My Tab 隐私政策

更新日期：2026年9月12日

Oh My Tab 提供自定义新标签页、常用网站整理与搜索功能。开发者不运营用于收集扩展数据的服务器，不在扩展中集成广告或分析追踪服务。

本地数据

网站标题和链接、文件夹、布局、搜索引擎、偏好、点阵图片与植物进度在扩展中保存在 Chrome 本地存储，在开发网页版中保存在 IndexedDB；背景原图和图标缓存由同一存储层管理。点击工具栏快捷收藏时读取当前标签页标题和网址，仅用于填写收藏表单；不持续读取浏览历史。点击浏览器书签「导入」并授权后，通过浏览器书签接口读取当前浏览器的书签标题、网址和文件夹结构，用于增量添加到首页；不修改或删除浏览器原有书签，不持续监听书签变化。可在浏览器扩展管理中管理该权限。书签导入、图片裁剪与点阵转换均在本地处理，背景图片按原始字节保存；导入图片不会上传给开发者，主动使用 WebDAV 上传备份时会发送到你指定的服务器。

搜索与可选联网服务

提交搜索时，关键词会发送给浏览器默认搜索服务，或你主动选择的搜索引擎；其页面遵循该服务的隐私政策。

搜索联想默认关闭。在新手教程或关于中启用并授权后，输入停顿250毫秒会将最多200字的关键词发送给当前选择的搜索服务，即使最终没有提交搜索。接收方包括 Google（suggestqueries.google.com）、Microsoft Bing（www.bing.com、cn.bing.com）、DuckDuckGo（duckduckgo.com）、Yahoo（search.yahoo.com）、Brave（search.brave.com）、Ecosia（ac.ecosia.org）及 Yandex（suggest.yandex.com），每次仅向当前选中的服务发送。浏览器默认、Startpage 与自定义引擎不请求在线联想。更换服务会取消未完成的旧联想请求。

网站图标下载默认关闭。启用并授权后，缓存缺失或手动刷新时，会将网站域名发送给 Favicon.im（a.favicon.im），失败时发送给 DuckDuckGo（icons.duckduckgo.com）。这些图标请求不发送书签标题、完整网址路径或查询参数。

上述联想和图标请求使用 HTTPS，不携带 Cookie 或来源页地址；接收服务仍会获得 IP 地址及处理请求所需的网络信息。各服务可能按自身政策保留请求日志，开发者无法代其承诺保留期限或删除第三方日志。

可选 WebDAV 备份

你可以自行填写 HTTPS WebDAV 目录和账户信息。点击连接、上传或下载时，扩展直接向所选服务器发送认证信息和相应请求。上传的 ZIP 包含网站标题与链接、布局、设置、点阵、植物进度、教程状态和原始背景图片，不经过开发者服务器。接收服务器会获得 IP 地址及请求信息，其数据保留由你或服务提供方管理。

服务器地址和用户名保存在当前设备；密码只在本次设置面板打开期间保留于内存，不包含在本地备份或同步文件中。数据不会定时自动上传；已有云端备份的覆盖与本机恢复需要确认。点击「删除」并确认后关闭连接、清除本机连接信息，不删除本地内容或服务器备份。可在浏览器扩展网站访问设置中撤销服务器权限。

控制、保留和删除

你可以在关于关闭联网服务并撤销其网站权限。关闭后停止新的服务请求，已经发送的数据无法撤回，已缓存图标仍保留。成功图标缓存保留至清除，失败记录15分钟后可重试。

书签可在界面删除。要清除全部本地设置和图标，可卸载扩展；备份需要单独删除。导出数据会下载 ZIP 文件，包含网站链接、设置和原图，内容未加密；仅应分享给可信接收者。隐私授权和 WebDAV 连接信息不会随备份导入。可在常规的「缓存 → 管理」查看分类用量，并确认清除所选本地数据；系统与授权记录保留。最近一天写入的闲置图片暂不清除。旧版 localStorage 数据保留为迁移副本，卸载扩展时一起删除。

数据用途与共享限制

用户数据仅用于上述功能，不出售，不用于广告、信用评估或与功能无关的用途。Oh My Tab 对用户数据的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 限制。
