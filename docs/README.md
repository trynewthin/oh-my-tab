## 资源目录

| 路径                 | 用途                                   |
| -------------------- | -------------------------------------- |
| `docs/brand/`        | 扩展图标的源文件                       |
| `docs/store-assets/` | 浏览器商店截图、宣传图和商品说明       |
| `website/`           | 产品官网与隐私政策前端                 |
| `materials/`         | 本地发布准备区，按平台分类且不纳入 Git |

## 维护规则

1. 根目录 README 只回答用户关心的问题，不放实现细节、审核记录或发布流水账。
2. 开发文档描述稳定的模块边界和操作方法；具体类型、默认值和功能清单以代码为准。
3. 商店文案只在 `docs/store-assets/description.txt` 维护，发布文档引用它，不复制正文。
4. 完整隐私政策正文只在 `website/src/i18n/locales/{zh-CN,en}.ts` 维护；发布时将相同内容同步到商店后台。
5. 测试生成文件统一写入 `tests/results/`；本地发布草稿写入被忽略的 `materials/`，不在根目录散落产物。

## 修改时同步检查

| 变更                     | 同步检查                              |
| ------------------------ | ------------------------------------- |
| 用户可见功能或安装方式   | 根目录 README、商店商品说明和截图     |
| 权限、联网服务或数据处理 | 隐私政策、商店权限说明和相关测试      |
| 模块职责或持久化结构     | 开发架构、迁移逻辑和单元测试          |
| 测试命令或目录           | 测试指南、`package.json` 和 CI 工作流 |
| 商店版本                 | 商品说明、素材、隐私托管页和扩展包    |
