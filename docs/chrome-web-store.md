# Chrome Web Store 提交材料

## 单一用途

提供可自定义的新标签页，帮助用户整理和访问常用网站，并从新标签页发起搜索。

## 商品说明

Oh My Tab 将新标签页变成常用网站工作台。支持拖拽书签、文件夹、多选整理、HTML 书签导入与本地配置备份；提供点阵时钟、像素绘图、植物组件和主题设置。

默认搜索跟随浏览器设置，也可主动选择或添加搜索引擎。书签和布局保存在本地。

可选联网功能默认关闭。启用搜索联想后，输入关键词会发送给当前选择的受支持搜索服务；启用网站图标下载后，网站域名会发送给图标服务。启用前会展示说明并请求相应网站权限，可在「设置→关于」随时关闭。服务接收方及数据处理详情见隐私政策。

## 权限用途

| 权限 | 提交说明 |
| --- | --- |
| activeTab | 用户点击工具栏快捷收藏时读取当前标签页标题和网址，用于填写收藏表单。 |
| search | 用户提交搜索时通过 Chrome search API 使用浏览器默认搜索服务。 |
| 搜索联想可选主机权限 | suggestqueries.google.com、www.bing.com、cn.bing.com、duckduckgo.com、search.yahoo.com、search.brave.com、ac.ecosia.org、suggest.yandex.com；仅在用户启用并授权后，向当前选择的服务请求关键词建议。 |
| https://a.favicon.im/* | 可选；用户启用图标下载后根据域名获取并本地缓存图标。 |
| https://icons.duckduckgo.com/* | 可选；主图标服务失败时获取域名对应图标。 |

## 隐私后台填报依据

按后台当时的分类如实申报：网站标题/网址的访问与本地存储，搜索输入向当前引擎的传输，图标域名向第三方的传输，以及服务接收到的网络信息。勿声明“不处理用户数据”。不出售数据、不用于单一用途之外的目的、不用于信用判断。无远程执行代码；网络响应仅作为建议文本和图片使用。

## 审核验证步骤

1. 安装后打开新标签页，确认能添加、整理常用网站。
2. 提交搜索，确认使用浏览器默认服务；主动切换后使用所选引擎。
3. 打开设置→关于，查看隐私政策和两项默认关闭的联网选项。
4. 启用搜索联想并允许网站权限，输入关键词查看建议；关闭后不再发起联想请求。
5. 启用图标下载并允许权限，确认图标加载；关闭后保留已有图标且不再下载。
6. 点击浏览器工具栏图标，验证当前页面快捷收藏。
