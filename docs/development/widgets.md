## 现有实例与占格

信息组件不使用 1×1；1×1 继续保留给图标级操作按钮。

| 组件     | 尺寸               | 首版行为                                   |
| -------- | ------------------ | ------------------------------------------ |
| 时钟     | 4×1、4×2、4×4      | 12/24 小时、可选秒、设备或指定时区         |
| 倒数日   | 2×2、4×1           | 单个事件，按日期自动正数或倒数             |
| 便签     | 4×4、4×8、8×4      | 卡片内直接编辑，最多 4000 字符             |
| 番茄钟   | 4×4                | 专注 1–180 分钟、休息 0–180 分钟、可选循环 |
| 天气     | 4×2、4×4           | 手动填写坐标，按需加载天气                 |
| 图片     | 4×4、4×8、8×4、8×8 | 单张本地图片与可选说明                     |
| RSS      | 8×4                | 手动加载订阅源标题                         |
| 世界时钟 | 4×4                | 最多 4 个具名 IANA 时区                    |

倒数日、番茄钟和下班倒计时可从添加目录新增；其余信息组件暂不展示，已保存的实例继续显示和编辑。书签列表和详细搜索框已移除，旧实例在加载或导入时丢弃。

下班倒计时仅提供 4×2 尺寸，保存上班和下班时间（本地 `HH:mm`）。每日重复，不区分工作日或节假日。下班早于上班时按跨午夜班次计算，两者相同不可保存。上班前显示距离上班，工作期间显示距离下班，到点后显示“自由时间”。三位小数表示毫秒，约每 32 ms 刷新；隐藏页面时暂停刷新，恢复后按当前时间计算。减少动态效果模式下每秒刷新并关闭动画。进度光点向出口移动，最后一分钟柔和脉冲，到点后短暂散开彩色光线。设置随 ZIP/WebDAV 备份保存，不产生网络请求。

尺寸、菜单、目录分类和创建默认值仍以
`src/lib/grid/registry.ts` 为单一事实来源。

## 状态与时间

现有组件数据作为 `GridItem` 可辨识联合的成员，继续进入网格 store、
ZIP 导入导出和 WebDAV 手动备份。非法持久化记录由既有导入校验拒绝。

便签直接更新当前 store 记录。番茄钟保存截止时间戳，而不是依赖
后台 interval 累计；`src/components/effects/use-wall-clock.ts` 为所有时间
组件提供共享、页面隐藏时暂停的显示时钟。重新打开页面时按时间戳恢复结果。

番茄钟默认不循环、无休息。专注结束后自动进入设定的休息阶段，休息为 0 时跳过；开启循环后自动继续下一轮。恢复页面时直接推算当前阶段及截止时间，不逐轮执行回调。休息阶段显示“休息”标记，暂停保留当前阶段，重置返回完整专注时长。修改专注或休息时长会重置计时，修改循环开关保留当前进度。旧记录缺失 `loop`、`breakMinutes`、`phase` 时分别按 `false`、`0`、`focus` 读取，新字段随现有 ZIP/WebDAV 备份保存。

## 联网与权限

已保存的天气和 RSS 实例默认不联网。只有用户点击“加载/刷新”时才会申请
该数据源的精确 HTTPS 主机权限并发送请求；修改配置、预览和恢复备份
都不会触发请求。

- 天气：访问 `api.open-meteo.com`，只发送手动填写的经纬度和单位，
  不调用设备定位。
- RSS：访问用户填写的公共 HTTPS 源，不使用代理，不发送登录 Cookie，
  不跟随重定向，也不执行远程 HTML。

远程请求使用 10 秒超时、1 MiB 响应上限、`credentials: omit`、
无 referrer 并支持取消。服务提供方仍能看到请求方 IP。远程响应只保留
在页面内存，不写入备份。

## 图片与备份

图片组件只接受 PNG/JPEG/WebP，输入文件最多 5 MiB。在本地栅格化并
重新编码为 WebP，最长边不超过 1024 像素，保存内容不超过 512 KiB。
不接受 SVG 或远程 URL，不保存原文件和原图元数据。

组件图片、便签、计时状态、坐标和订阅源地址会进入现有
未加密 ZIP，以及用户主动上传的 WebDAV 备份。隐私授权本身不进入备份。
