# 界面打磨记录

## 状态与范围

本轮基于 `5b57553f42e732f003d297cbf09e2d2a619e29c5`，在独立分支上提出修改，不重写 `main` 历史、不合并、不发布。

这是需要视觉验收的草稿，不是“获奖级设计已完成”的结论。范围是共享界面反馈、设置行响应式、官网首页和隐私页样式。没有改动存储、权限、网格坐标、组件目录、WebDAV、星轨或 PixiJS 渲染器。

## 设计取舍

保留真实产品截图、点阵字标、像素植物和原有柔和配色，不引入库存插画、外部字体服务、装饰性渐变或虚构产品界面。官网承担介绍与展示；扩展承担高频操作，两者不套用同一种展示密度。

首页从统一居中改为标题与操作区分工，使用同一内容对齐线、章节编号和有节制的错位编排。细节截图不再通过悬浮位移暗示可以点击。主题按钮保留原生按钮语义，预览为共享固定比例区域，仅当前主题图片暴露给辅助技术。

页脚点阵从持续闪烁改为静态字标，在悬停或键盘聚焦时响应。没有滚动劫持、延迟展示正文或新增逐帧调度。减少动态效果时关闭新增过渡和按压位移。

## 八项检查

### 排版

官网实际加载本地 Inter Variable，而非只声明 Inter 字体名。扩展与官网补全系统和中文回退字体。中英文标题分别控制字距与行高，正文控制阅读宽度。仍需比较真实字体渲染和换行，尤其是英文长标题。

### 留白

统一官网内容宽度、边距、区段间距和图文间距。细节图使用固定比例展示区域。设置行在窄面板内堆叠标签和控件，不再按长标签的最大内容宽度分配列宽。真实截图仍需检查边距与密度。

### 视觉层级

首屏标题、安装操作、次级下载入口、预览工具栏分层。章节标题与编号建立阅读顺序。隐私页保留清晰的摘要、目录和正文结构。

### 色彩

保留墨色背景与原有紫色强调，移除背景光晕。正文、次级正文、按钮和边框使用明确的共享变量。没有修改用户保存的主题与组件配色。静态变量对比度计算不等于全页面无障碍通过。

### 动效

按钮只过渡颜色、边框、阴影和按压位移，不使用无边界的 `transition-all`，也不触碰拖拽 transform。官网取消持续点阵动画和非交互图片的悬浮运动。星轨与 PixiJS 的性能和观感不在本轮已验证范围内。

### 微交互

主题按钮有选中状态和明确的受控区域；隐藏主题图片不重复朗读。触控与鼠标悬停分开处理，键盘和强制色彩模式保留焦点标记。页面切换、慢网加载、图片失败、键盘遍历仍需浏览器验收。

### 响应式

官网移动端保留功能、界面和隐私导航。小屏安装操作移到首屏，避免页头挤压。设置按容器宽度响应，补充安全区与滚动边界。目标验收宽度为 320、390、768、1024 和 1440 CSS 像素；这些尺寸尚未逐一实测。

### 原创性

视觉元素来自本项目已有的网格、点阵和真实截图，不模仿某个获奖站点的布局或品牌。原创性与整体完成度仍需人工视觉判断，不能由源代码断言或自动打分替代。
