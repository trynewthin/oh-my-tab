# 组件视觉设计

现有信息组件的视觉设计。倒数日、番茄钟与下班倒计时已在添加目录展示；其余信息组件暂不展示，已保存的实例继续可用。书签列表已移除。

## 和已有桌面保持一致

复用 `ComponentBackground` 的纯色、柔光、噪点和背景玻璃效果，沿用现有圆角、边框、Inter 字体、Phosphor 图标及明暗主题。信息内容使用主题前景色；自选颜色用于少量强调、进度和装饰，不直接拿高亮色渲染正文。设置项复用 `SettingItem`；日期选择器使用项目 shadcn 配置下的 Calendar 与 Popover。

网格真实尺寸来自 `gridOccupancyBox`：4×1 是 286×59.5，4×2 是 286×135，4×4 是 286×286，8×4 是 588×286。短卡片单独排版，不把完整大卡片等比例塞进小尺寸。

## 每类组件的信息重点

- 下班倒计时：`HH:mm:ss.fff` 为主体，小数弱化着色，进度光点向出口推进，最后一分钟柔和脉冲，到点后开门并短暂散开彩色光线。4×2 将状态文字、时间与小数放在同一行，不展示上下班时间段；遵循减少动态效果设置。

- 时钟：主数字、弱化的秒数/时段、日期。4×1 是横条，4×2 是紧凑上下结构，4×4 留出空间。保留完整读屏时间。
- 倒数日：不显示卡片标题和辅助描述；空状态仅包含圆形加号按钮与“添加事件”，2×2 上下排列，4×1 左右排列。每个实例只负责一个事件，编辑框平铺标题和日期；2×2 居中显示大号天数及下方小号事件名称；4×1 单行显示左侧事件、右侧天数与“天”。长数字缩字，不截断数值。
- 便签：无额外文本框边框，直接书写；字数提示在输入聚焦时出现，不常驻抢占视线。
- 番茄钟：放大加粗的进度环，环内显示等宽剩余时间，组件右下角为圆形开始／暂停图标按钮，左下角为圆形终止图标按钮；终止后恢复完整专注时长，左上角显示工作／休息状态，右上角圆形计数按钮显示今日完成次数，点击查看完整次数；不展示标题、设置按钮和辅助描述。
- 天气：温度与天气图标优先，预报横向并列。保留服务署名、单位、手动刷新、取消和错误状态。
- 图片：画面铺满原卡片，说明为小型浮层，不使用贯穿底部的黑条；预览采用本地插画作为示例，不请求远程图片。
- RSS：编号、标题、来源，使用轻分隔，不在卡片里再套卡片；长标题换行，完整标题可访问。
- 世界时钟：小表盘与数字并列，城市与日期形成次层级。日夜标记表示当地钟点范围，不冒充天文日出日落。

## 编辑和交互

编辑器使用现有 Base UI/shadcn 的 Switch、Select、ToggleGroup、ColorPicker。桌面双栏展示实际比例预览与配置，窄屏上下排列；所有更改仍需保存，不为预览写入 store。联网组件的预览明确标记为示例，不发请求。

只有支持悬停的设备才淡出次级设置操作；键盘聚焦和触屏仍能访问。遵守减少动态效果及强制颜色偏好。列表继续复用 collection 滚动和行结构。输入、链接和按钮阻止拖拽事件冒泡，卡片留白保留拖动能力。

## 验收边界

纯函数与服务端渲染测试不启动浏览器，只检查分派、格式化、预览副作用和中英文输出。它们不证明布局或美感已验收。浏览器逐尺寸验收和截图仍须维护者单独授权；未获得授权时不得标为通过。
