# Oh My Tab v1.5.0

本次更新带来统一数据存储、原图 ZIP 备份和 WebDAV 多端手动同步。

1. 扩展使用 Chrome 本地存储，开发网页使用 IndexedDB，支持迁移旧版数据与跨页面写入冲突保护。
2. 支持 ZIP 手动备份和恢复，保存原始背景图片，并校验数据完整性；旧版 OMT1 文本可作为文件导入。
3. 新增 WebDAV 连接管理、上传和下载恢复，覆盖前确认并检查远端版本，附带 Docker 自部署方案。
4. 新增分类用量与选择性清理，可直接授权导入浏览器书签。
5. 设置分类简化为常规、主页、搜索、个性化与关于；统一控件背景与边框，主页设置分为顶部和搜索框。
6. 简约搜索框与左侧按钮视觉统一，联想面板跟随输入框宽度；关于页新增项目支持入口。

## 升级说明

1. 新增 `storage`、`unlimitedStorage` 权限，浏览器书签权限按需申请；WebDAV 仅请求用户指定服务器的访问权限。
2. 原图从本版本起按原始字节保存，旧版已压缩图片无法恢复为原图，需重新上传。
3. WebDAV 为手动快照同步，下载恢复会替换本地数据，ZIP 未加密。请使用可信的 HTTPS 服务。

## 安装

下载 ZIP 并解压，在 Chrome / Edge 扩展管理页开启开发者模式，选择「加载已解压的扩展程序」。已有安装请重新加载扩展。CRX 使用项目固定密钥签名；浏览器可能限制商店外 CRX 安装。

本次发布通过代码静态检查、类型检查、25 项单元测试，以及 Apache WebDAV / Caddy HTTPS 的网页与 Chrome 扩展集成验证。集成验证使用独立测试数据、测试证书及预授权的测试主机，不包含首次授权弹窗。
