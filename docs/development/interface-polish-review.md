## 具体界面变化

### 新标签页

自由布局的顶栏改为有明确时间、日期层级的页眉；两侧为工具入口，中间为时间或用户原有文字。沿用网格计算得到的实际宽度，保留用户的顶栏配置、网格坐标与背景配色。主搜索框提升输入区的尺寸和阅读权重，内嵌搜索组件不受影响。中尺寸书签增加实际域名作为次级信息，小尺寸继续单行，链接的可访问名称和目标不变。

### 设置与组件库

共用工作区改为侧栏、页头、内容三个区域：侧栏承担分类，页头显示当前分组和页面标题，内容区域独立滚动。不再隐藏当前页标题，也不把导航滚动百分比作为视觉焦点。导航使用可读的前景色与选中标记，用户主题色只控制边界和低浓度背景。

组件库把真实预览、名称、完整说明与尺寸信息放在独立区域，不再用磨砂字幕遮挡预览或截断说明。点击区域与预览是同级节点，避免把含控件的真实组件嵌套在按钮里。详情采用预览与尺寸选项并排布局，尺寸选项同时呈现比例图形和数值；添加和取消操作不覆盖预览。

### 组件编辑器

显示标题和说明；预览台、表单与操作区分离。移除旧的绝对定位浮动表单和预览重叠算法，根据实际可用空间等比例缩放真实组件，保留主页的比例上限。大尺寸不会被表单挡住。表单独立滚动，保存操作不在字段滚动区域内；窄屏转为预览在上、表单在下的自然顺序。

### 材质与交互

材质页将菜单中的纹理改为可比较的样片阵列，保留真实材质绘制和原有大幅动态预览。小样片使用静态绘制，不新开持续动画。样片支持方向键和 Home / End，选择后更新真实预览；顶栏工具也增加方向键切换。
