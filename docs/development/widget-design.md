# 组件视觉设计

新增九类组件的视觉层；注册表、占格、权限与持久化模型不变。

## 和已有桌面保持一致

复用 `ComponentBackground` 的纯色、柔光、噪点和背景玻璃效果，沿用现有圆角、边框、Inter 字体、Phosphor 图标及明暗主题。信息内容使用主题前景色；自选颜色用于少量强调、进度和装饰，不直接拿高亮色渲染正文。不引入第二套 UI 框架或新增依赖。

网格真实尺寸来自 `gridOccupancyBox`：4×1 是 286×59.5，4×2 是 286×135，4×4 是 286×286，8×4 是 588×286。短卡片单独排版，不把完整大卡片等比例塞进小尺寸。

## 每类组件的信息重点

- 时钟：主数字、弱化的秒数/时段、日期。4×1 是横条，4×2 是紧凑上下结构，4×4 留出空间。保留完整读屏时间。
- 倒计时：第一个事件的天数作为主体，4×4 在下方列出其他日期。长数字缩字或换行，不截断数值。
- 便签：无额外文本框边框，直接书写；字数提示在输入聚焦时出现，不常驻抢占视线。
- 专注计时：细线进度环、稳定等宽数字、一个主要操作。重置与设置保持次级。
- 天气：温度与天气图标优先，预报横向并列。保留服务署名、单位、手动刷新、取消和错误状态。
- 图片：画面铺满原卡片，说明为小型浮层，不使用贯穿底部的黑条；目录采用本地插画作为示例，不请求远程图片。
- 书签列表：标记、标题、弱化域名。不复制文件夹数据，不新增图标网络请求。
- RSS：编号、标题、来源，使用轻分隔，不在卡片里再套卡片；长标题换行，完整标题可访问。
- 世界时钟：小表盘与数字并列，城市与日期形成次层级。日夜标记表示当地钟点范围，不冒充天文日出日落。

## 编辑和交互

编辑器使用现有 Base UI/shadcn 的 Switch、Select、ToggleGroup、ColorPicker。桌面双栏展示实际比例预览与配置，窄屏上下排列；所有更改仍需保存，不为预览写入 store。联网组件的预览明确标记为示例，不发请求。

只有支持悬停的设备才淡出次级设置操作；键盘聚焦和触屏仍能访问。遵守减少动态效果及强制颜色偏好。列表继续复用 collection 滚动和行结构。输入、链接和按钮阻止拖拽事件冒泡，卡片留白保留拖动能力。

## 验收边界

纯函数与服务端渲染测试不启动浏览器，只检查分派、格式化、预览副作用和中英文输出。它们不证明布局或美感已验收。浏览器逐尺寸验收和截图仍须维护者单独授权；未获得授权时不得标为通过。
