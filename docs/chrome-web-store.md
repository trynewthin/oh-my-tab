# Chrome Web Store 提交材料

## 单一用途

提供可自定义的新标签页，帮助用户整理和访问常用网站，并从新标签页发起搜索。

## 商品说明

Oh My Tab 将新标签页变成常用网站工作台。支持拖拽书签、文件夹、多选整理、直接导入浏览器书签、原图 ZIP 备份与可选 WebDAV 手动同步；提供点阵时钟、像素绘图、植物组件和主题设置。

默认搜索跟随浏览器设置，也可主动选择或添加搜索引擎。书签和布局保存在本地。

可选联网功能默认关闭。启用搜索联想后，输入关键词会发送给当前选择的受支持搜索服务；启用网站图标下载后，网站域名会发送给图标服务。启用前会展示说明并请求相应网站权限，可在「设置→关于」随时关闭。服务接收方及数据处理详情见隐私政策。

## 权限用途

| 权限 | 提交说明 |
| --- | --- |
| activeTab | 用户点击工具栏快捷收藏时读取当前标签页标题和网址，用于填写收藏表单。 |
| search | 用户提交搜索时通过 Chrome search API 使用浏览器默认搜索服务。 |
| storage | 在扩展本地保存书签、布局、个性化、原图、缓存和设备连接设置。 |
| unlimitedStorage | 保存用户原始背景图片及本地数据，避免原图受默认配额限制；实际可用空间仍取决于设备。 |
| bookmarks（可选） | 用户点击导入并授权后读取书签标题、网址和目录结构，用于增量添加到首页，不修改浏览器原有书签。 |
| https://*/*（可选主机范围） | 用于用户自选 HTTPS WebDAV 服务，以及搜索联想和图标下载。运行时只申请当前功能所需的具体主机。 |

## 隐私后台填报依据

按后台当时的分类如实申报：网站标题/网址的访问与本地存储，搜索输入向当前引擎的传输，图标域名向第三方的传输，用户指定 WebDAV 服务器接收的认证信息和完整数据备份，以及服务接收到的网络信息。勿声明“不处理用户数据”。不出售数据、不用于单一用途之外的目的、不用于信用判断。网络响应仅作为数据处理，不执行远程代码。

## 审核验证步骤

1. 安装后打开新标签页，确认能添加、整理常用网站。
2. 提交搜索，确认使用浏览器默认服务；主动切换后使用所选引擎。
3. 打开设置→关于，查看隐私政策和两项默认关闭的联网选项。
4. 启用搜索联想并允许网站权限，输入关键词查看建议；关闭后不再发起联想请求。
5. 启用图标下载并允许权限，确认图标加载；关闭后保留已有图标且不再下载。
6. 点击浏览器工具栏图标，验证当前页面快捷收藏。
7. 在「常规」点击「从浏览器书签导入」的「导入」，授权后验证增量添加和网址去重。
8. 手动备份 ZIP 并恢复，确认原图保留及恢复前的覆盖提示。
9. 将「多端同步」选为 WebDAV，在管理面板连接自己的 HTTPS 目录，验证上传、下载确认和删除连接；删除连接不删除本地内容或云端备份。
