## 组件与占格

新增信息组件不使用 1×1；1×1 继续保留给图标级操作按钮。

| 组件 | 尺寸 | 首版行为 |
| --- | --- | --- |
| 时钟 | 4×1、4×2、4×4 | 12/24 小时、可选秒、设备或指定时区 |
| 倒计时 | 4×2、4×4 | 最多 4 个事件，按日历日期计算天数 |
| 便签 | 4×4、4×8、8×4 | 卡片内直接编辑，最多 4000 字符 |
| 专注计时器 | 4×4 | 1–180 分钟，开始、暂停、重置和今日完成次数 |
| 天气 | 4×2、4×4 | 手动填写坐标，按需加载当前天气和 3 天高低温 |
| 图片 | 4×4、4×8、8×4、8×8 | 单张本地图片、填充/完整显示及可选说明 |
| 书签列表 | 4×4、4×8 | 引用已有文件夹，直接滚动访问链接 |
| RSS | 8×4 | 手动加载 RSS 2.0、RDF 或 Atom，最多 5 条标题 |
| GitHub 仓库 | 4×2、4×4 | 公开仓库星标、Fork、Issues + PRs 和最近推送 |
| 世界时钟 | 4×4 | 最多 4 个具名 IANA 时区 |

尺寸、菜单、目录分类和创建默认值仍以
`src/lib/grid/registry.ts` 为单一事实来源。

## 状态与时间

新数据作为现有 `GridItem` 可辨识联合的成员，继续进入网格 store、
ZIP 导入导出和 WebDAV 手动备份。非法持久化记录由既有导入校验拒绝。

便签直接更新当前 store 记录。专注计时器保存截止时间戳，而不是依赖
后台 interval 累计；`src/components/effects/use-wall-clock.ts` 为所有时间
组件提供共享、页面隐藏时暂停的显示时钟。重新打开页面时按时间戳恢复结果。

## 联网与权限

天气、GitHub 和 RSS 默认不联网。只有用户点击“加载/刷新”时才会申请
该数据源的精确 HTTPS 主机权限并发送请求；添加组件、目录预览、修改配置
和恢复备份都不会触发请求。

- 天气：访问 `api.open-meteo.com`，只发送手动填写的经纬度和单位，
  不调用设备定位。
- GitHub：访问 `api.github.com`，只查询公开 `owner/repository`，
  不读取登录状态或保存令牌。
- RSS：访问用户填写的公共 HTTPS 源，不使用代理，不发送登录 Cookie，
  不跟随重定向，也不执行远程 HTML。

远程请求使用 10 秒超时、1 MiB 响应上限、`credentials: omit`、
无 referrer 并支持取消。服务提供方仍能看到请求方 IP。远程响应只保留
在页面内存，不写入备份。

## 图片与备份

图片组件只接受 PNG/JPEG/WebP，输入文件最多 5 MiB。在本地栅格化并
重新编码为 WebP，最长边不超过 1024 像素，保存内容不超过 512 KiB。
不接受 SVG 或远程 URL，不保存原文件和原图元数据。

组件图片、便签、计时状态、坐标、公开仓库标识和订阅源地址会进入现有
未加密 ZIP，以及用户主动上传的 WebDAV 备份。隐私授权本身不进入备份。
