## 单一用途

提供可自定义的新标签页，帮助用户整理和访问常用网站，并从新标签页发起搜索。书签、布局、顶栏的网页入口与操作配置、偏好和图片保存在本地；用户可以导出备份，或主动使用自选 HTTPS WebDAV 服务手动传输。

## 权限说明

| 权限                | 提交说明                                                                                                |
| ------------------- | ------------------------------------------------------------------------------------------------------- |
| `activeTab`         | 用户点击工具栏快捷收藏时读取当前标签页标题和网址，用于填写收藏表单。                                    |
| `search`            | 用户提交搜索时通过 Chrome Search API 使用浏览器默认搜索服务。                                           |
| `storage`           | 在扩展本地保存书签、布局、顶栏配置、个性化、原图、缓存和设备连接设置。                                  |
| `unlimitedStorage`  | 保存用户原始背景图片及本地数据，避免原图受默认配额限制。                                                |
| `bookmarks`（可选） | 用户主动导入并授权后读取书签标题、网址和目录结构，不修改浏览器原有书签。                                |
| HTTPS 主机（可选）  | 访问用户选择的 WebDAV、搜索联想、图标及手动天气、GitHub、RSS 服务；运行时只申请当前功能所需的具体主机。 |

隐私后台应如实申报网站标题和网址的本地存储、搜索输入向所选服务的传输、网站域名向图标服务的传输、手动天气坐标/公开仓库标识/完整订阅源 URL 的传输，以及用户指定 WebDAV 服务接收的认证信息和完整备份。不得声明“不处理用户数据”。产品不出售数据，不将数据用于产品单一用途之外的目的，也不执行远程代码。

## 生成商店图片

1. 启动开发页面：`npm run dev -- --host 127.0.0.1`。
2. 在另一个终端运行：`npm run store-assets`。
3. 脚本会验证五张功能图均为 1280×800 RGB PNG，宣传图分别为 440×280 和 1400×560。
4. 人工确认截图使用当前界面和公开示例数据，没有测试标记或个人信息。

## 审核验证步骤

1. 安装后打开新标签页，添加并整理常用网站；在自由网格中配置顶栏的系统操作和网页入口。
2. 提交搜索，确认默认使用浏览器搜索设置。
3. 在「设置 → 关于」查看隐私政策和默认关闭的联网选项。
4. 分别启用搜索联想与图标下载，验证授权、请求和关闭后的行为。
5. 点击工具栏图标，验证当前页面快捷收藏。
6. 主动授权导入浏览器书签，验证增量添加和网址去重。
7. 导出并恢复 ZIP，确认覆盖提示和原始背景图片。
8. 连接 HTTPS WebDAV，验证上传、下载确认和删除连接。

## 提交检查

1. 运行 `npm run check`、`npm run build`、`npm test` 和 `npm run test:extension`。
2. 确认扩展 ZIP 根目录直接包含 `manifest.json`。
3. 确认 `https://ohmytab.vercel.app/privacy` 已发布当前政策，并核对后台数据声明。
4. 上传 `docs/store-assets/description.txt`、五张功能截图和两张宣传图。
5. 根据 `public/manifest.json` 核对权限理由，不沿用旧版本的权限列表。
6. 在后台完成账号验证、两步验证和隐私声明后提交审核。

本地材料和扩展包不表示已经公开发布或通过审核。

## 扩展组件库送审核对

新增时钟、倒计时、便签、专注计时器、天气、图片、书签列表、RSS、GitHub 仓库和世界时钟。尺寸、数据边界和联网行为见[扩展组件库](../development/widgets.md)。

天气、GitHub 和 RSS 只由卡片“加载/刷新”触发精确主机授权和请求；不自动定位、读取浏览历史、登录账户、剪贴板或第三方令牌。目录预览使用固定示例数据且不联网。GitHub 开放项计数包含 PR，因此界面标为“议题与 PR”。

图片组件仅接收本地 PNG/JPEG/WebP，在本地重新编码为最长边不超过 1024 像素且单张不超过 512 KiB 的 WebP。便签、计时状态、图片和其他组件配置会随现有未加密 ZIP/WebDAV 备份传输。商店后台和托管隐私政策必须与这些行为保持一致。
