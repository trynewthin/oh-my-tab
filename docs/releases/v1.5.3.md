## Oh My Tab 1.5.3

### 中文

- 新增 1×1 快捷按钮，可绑定主题切换、一键整理、多选、打开设置或组件库。
- 简约搜索框支持 4×1、8×1、12×1 三种大小，支持整体拖动，两侧图标与间距更协调。
- 组件库按用途分类，预览沿用实际组件并等比缩放；可直接选择尺寸，再点击添加。
- 改善组件卡片的深色背景、边界与描述排版，以及小屏幕下的应用导航。
- 普通搜索框不再出现在组件库中；已有实例保留并以简约样式显示。
- 新增英文 README，并提供中英文文档切换入口。

### English

- Add 1×1 shortcut buttons for theme switching, grid cleanup, multi-selection, settings, and the component catalog.
- Offer the minimal search widget in 4×1, 8×1, and 12×1 sizes, with whole-widget dragging and refined icon spacing.
- Organize the component catalog by category, scale actual widgets for previews, and separate size selection from adding a widget.
- Improve dark card surfaces, borders, single-line descriptions, and application navigation on smaller screens.
- Remove the full search widget from the catalog. Existing instances are retained and displayed in the minimal style.
- Add an English README with links between English and Chinese documentation.

### Installation / 安装

Download the ZIP, extract it, enable Developer mode in Chrome or Edge's extensions page, and choose **Load unpacked**. Select the directory containing `manifest.json`.

下载 ZIP 并解压，在 Chrome / Edge 扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的目录。

The CRX is signed with the project's existing key. Browsers may restrict installation of CRX files outside the store. Chrome Web Store availability depends on review progress.

CRX 使用项目现有密钥签名；浏览器可能限制商店外 CRX 安装。Chrome 应用商店版本以上架审核进度为准。
